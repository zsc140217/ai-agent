## 🐛 常见问题

### Q1：测试运行失败，报错 "Connection refused"
**原因**：服务没启动或端口不对  
**解决**：
1. 确认 `run-backend.bat` 已运行
2. 访问 `http://localhost:8123/api/health` 确认服务正常

### Q2：测试运行很慢，一直卡住
**原因**：API Key 无效或网络问题  
**解决**：
1. 检查 `application.yml` 中的 `api-key` 是否有效
2. 尝试手动调用一次接口测试：
   ```bash
   curl "http://localhost:8123/api/ai/enterprise/chat/sync?message=测试&chatId=test"
   ```

### Q3：准确率很低（<30%）
**原因**：知识库没加载或向量库为空  
**解决**：
1. 确认 `src/main/resources/document/*.md` 文件存在
2. 重启服务，观察启动日志是否有"加载文档"相关信息

### Q4：所有用例都失败
**原因**：测试数据文件不存在  
**解决**：
1. 确认 `src/test/resources/evaluation/rag_test_cases.json` 存在
2. 检查文件内容是否是有效的 JSON 格式
